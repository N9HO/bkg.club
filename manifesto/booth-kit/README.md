# BKG Hamfest Booth Kit

Print-ready pieces built from the distilled manifesto, using the BKG emblem and the brass-and-black look.

| File | Size | Use |
| --- | --- | --- |
| `BKG_Booth_Card_5.5x8.5.pdf` | 5.5 x 8.5 in | Handout / take-away card. Prints two per Letter sheet. |
| `BKG_Table_Sign_8.5x11.pdf` | 8.5 x 11 in | Table-top sign for the booth. Fits a standard Letter frame or sign holder. |
| `BKG_Poster_18x24.pdf` | 18 x 24 in | Large-format poster for the backdrop or an A-frame. |

All three carry the same message: grow the code, own 2 meters, bring back the tinker, build the crew. Text is free of hyphens and dashes throughout.

Printing notes:
- PDFs are fixed-size at their listed dimensions. Print at 100 percent (no scaling) to keep the sizes exact.
- The poster is set up for full-bleed edges. If your printer needs a margin, print with "fit to printable area."
